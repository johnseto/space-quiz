# Orbit Quiz

Orbit Quiz is a standalone space-exploration quiz. Answer 10 multiple-choice questions, learn a fact after each answer, and see your score and personal best at the end.

## Run locally

Open `index.html` in a browser. The app is a single file and needs no server, build step, package installation, or external dependency.

## Deployment

The site is published with GitHub Pages at <https://johnseto.github.io/space-quiz/>. Changes merged to `main` are deployed automatically by the GitHub Actions workflow.
